# ほぼ週刊ググレカス

Hugo static export of published posts from the WordPress site [ほぼ週刊ググレカス](https://laiken.net/ggrks).

Live site: https://souljazzfunk.github.io/ggrks/

Source Markdown in `content/` is built by GitHub Actions (Hugo extended 0.151.2) and deployed to GitHub Pages. Posts only; no static pages or contact form.
