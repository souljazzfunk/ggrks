# ほぼ週刊ググレカス

Hugo static export of published posts from the WordPress site [ほぼ週刊ググレカス](https://laiken.net/ggrks).

Live site: https://souljazzfunk.github.io/ggrks/

Source Markdown in `content/` lives on `main`. The built site (Hugo extended 0.151.2) is published from the `gh-pages` branch. Posts only; no static pages or contact form.
